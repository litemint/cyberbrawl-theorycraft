Cyberbrawl's [smart contracts source](https://github.com/litemint/cyberbrawl-contracts) is public under the MIT license, and every release is built from a tagged commit by a public workflow, so the code you read is the code that runs.

Although players can call the contract methods themselves, from their own wallet, the game can handle all contract calls on their behalf, covering the fees and all technical aspects seamlessly.

Source: [github.com/cyberbrawl-contracts](https://github.com/litemint/cyberbrawl-contracts)  
Releases: [github.com/litemint/cyberbrawl-contracts/releases](https://github.com/litemint/cyberbrawl-contracts/releases)
